# Taiwan Night Market Calorie Database（台灣夜市小吃熱量資料庫）

台灣夜市小吃熱量與營養素結構化資料庫。收錄 35+ 種常見夜市食物的熱量、蛋白質、脂肪、碳水化合物，以及減重友善選擇指南和台灣夜市飲食的代謝科學背景。數據來源為衛福部食藥署 TFND 及同行評審研究。

## 為什麼夜市是台灣人最需要攻克的飲食場景

台灣 **90% 以上民眾**每月至少光顧夜市一次，估計超過 **60% 的台灣人**每週吃夜市。但夜市食物的熱量資訊極度不透明：

- **份量標準不統一**：一份「大腸包小腸」可能是 350 kcal，也可能是 550 kcal，取決於攤販手感
- **隱形油脂多**：炸物、鹹酥雞、大腸煎的油脂含量通常被嚴重低估 30–50%
- **精製碳水主導**：麵線、臭豆腐炸皮、米血糕等食物升糖指數高，飽足感低，容易過量
- **蛋白質密度低**：夜市常見的高熱量食物，蛋白質比例普遍不足 10%（理想 ≥ 20–25%）

**關鍵認知**：知道熱量只是第一步。了解食物的蛋白質密度（每 100 kcal 含多少克蛋白質），才能在夜市中選出「吃飽又不超標」的組合。

## 減重友善選擇（熱量 < 400 kcal 且蛋白質 > 10g）

在夜市維持熱量目標的關鍵是「高蛋白優先、炸物限量、含糖飲料歸零」策略：

| 推薦選擇 | 熱量 | 蛋白質 | 策略理由 |
|---------|------|--------|---------|
| 烤雞腿（不吃皮）| ~260 kcal | 28g | 高蛋白低碳，夜市最佳選項 |
| 臭豆腐（蒸或滷，非炸）| ~200 kcal | 16g | 選蒸臭豆腐可省去 160 kcal |
| 烤豆腐（少醬）| ~160 kcal | 12g | 蛋白質密度高，升糖指數低 |
| 蚵仔煎（少粉漿）| ~280 kcal | 14g | 要求少粉漿可減少 50 kcal |
| 花枝丸（3 顆）| ~220 kcal | 12g | 選蒸/煮，避免油炸 |

## 台灣夜市熱量的隱形陷阱

| 陷阱 | 說明 | 實際影響 |
|------|------|---------|
| **醬料熱量被低估** | 每份醬油膏、沙茶醬、花生醬約 60–120 kcal | 一餐可能多攝取 200–400 kcal |
| **含糖飲料不被算入「餐點」** | 珍珠奶茶被視為「飲料」，但熱量等同一份主食 | 最常見的熱量黑洞 |
| **花生粉** | 潤餅的花生粉每份約 3–4 湯匙，約 120 kcal | 熱量密度極高，卻幾乎沒有飽足感貢獻 |
| **米血糕、糯米類食物** | 消化快、升糖指數高，容易在 1–2 小時後飢餓 | 增加全天總攝取量 |
| **炸物反復使用的油** | 高溫炸油中的氧化脂質和反式脂肪 | 代謝健康影響超出熱量本身 |

## 夜市飲食的最高 ROI 策略

1. **含糖飲料換無糖茶或水**：一杯全糖珍珠奶茶（430 kcal）→ 無糖綠茶（0 kcal）= 每次節省 430 kcal
2. **炸 → 烤**：炸臭豆腐（360 kcal）→ 蒸臭豆腐（200 kcal）= 節省 160 kcal
3. **加點蛋白質**：任何攤位旁若有烤雞腿或蒸蛋，優先補充蛋白質可延長飽足感 2–3 小時
4. **醬料放一半**：每份醬料減半，平均省 60–100 kcal
